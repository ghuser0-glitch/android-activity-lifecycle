# android-activity-lifecycle

A simple Android project demonstrating the complete Android Activity Lifecycle (`onCreate`, `onStart`, `onResume`, `onPause`, `onStop`, `onRestart`, `onDestroy`) using two activities (`MainActivity` and `SecondActivity`).

## Features
- Logs all state changes directly to Android Studio's **Logcat** using descriptive custom tags (`Lifecycle_MainActivity` and `Lifecycle_SecondActivity`).
- Demonstrates state transitions when navigating between activities or returning to the main screen.
